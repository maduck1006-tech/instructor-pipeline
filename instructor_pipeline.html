👋
WELCOME
강사 섭외 파이프라인에
오신 걸 환영합니다
이 툴은 타겟 → 문제 → 강사 매칭 순서로
온라인 교육 콘텐츠를 기획하는 도구입니다.

사람을 먼저 찾는 게 아니라, 고객의 고통을 먼저 정의하고
그에 맞는 강사를 찾는 방식으로 기획 시간을 단축합니다.
⏱ 설명은 약 1분 소요됩니다. 언제든 건너뛸 수 있어요.
🎯
STEP 1
타겟 × 주제 탭
먼저 공략할 타겟과 핵심 고통을 정의합니다.

• + 타겟 추가 버튼으로 새 행 추가
• ✦ AI 버튼을 클릭하면 대분류·연령·고통 입력 후 나머지 칸을 AI가 자동완성
• 자동점수(S/A/B/C)는 시급성·지불의사·기존지출·경쟁포화를 자동 계산
💡 셀을 클릭하면 팝업으로 바로 수정할 수 있습니다.
Ctrl+Z로 언제든 되돌리기 가능합니다.
🎤
STEP 2
강사 DB 탭
+ 강사 추가를 클릭하면 AI 분석 팝업이 열립니다.

• 강사의 인스타그램/유튜브 주소를 입력하면
  AI가 적합한 주제를 자동으로 매칭해줍니다
• 진심도⭐와 공감력⭐는 별점 클릭으로 즉시 변경
• 필터로 상태·채널·난이도·주제별 강사 필터링 가능
💡 강사 수 숫자를 클릭하면 해당 주제의 강사 목록을 바로 볼 수 있어요.
📋
STEP 3
칸반 보드 & 미팅 로그
칸반 보드에서 강사 카드를 드래그해
미컨택 → 컨택중 → 미팅확정 → 협의중 → 완료
상태를 바꿀 수 있습니다.

미팅 로그에서 강사명을 클릭해 강사를 연결하면
담당 주제가 자동으로 연동됩니다.
⚡
단축키
알아두면 편한 기능들
• Ctrl+Z 무한 되돌리기 (수정/삭제 모두)
• 삭제 시 5초 안에 "되돌리기" 클릭하면 복구
• 상단 CSV/엑셀 버튼으로 데이터 내보내기
• 데이터는 Supabase 클라우드에 자동 저장
  어떤 기기·브라우저에서든 동일한 데이터

📖 도움말

시작하기

1. 타겟 정의
타겟 × 주제 탭에서 공략할 고객의 고통을 먼저 정의하세요. ✦ AI 버튼으로 자동완성 가능.
2. 강사 추가
강사 DB 탭에서 + 강사 추가 클릭. SNS 주소 입력 시 AI가 적합한 주제를 매칭합니다.
3. 상태 관리
칸반 보드에서 드래그로 섭외 단계를 관리하세요.
4. 미팅 기록
미팅 로그에서 강사와의 대화 내용과 다음 액션을 기록하세요.

셀 편집

셀 클릭
모든 셀을 클릭하면 팝업이 뜨고 바로 수정할 수 있습니다.
드롭다운 셀
대분류, 상태, 시급성 등은 클릭 시 선택 팝업이 열립니다.
별점
진심도/공감력은 별★을 직접 클릭해서 즉시 변경합니다.

AI 기능

타겟 자동완성
타겟 행의 ✦ AI 버튼 → 대분류+연령+고통 입력 → AI가 슬로건, 결과, 시급성 등을 채워줍니다.
강사 AI 분석
+ 강사 추가 → SNS 주소 입력 → AI가 적합한 주제 매칭 + 프로필 분석.

자동점수 기준

S급 (10점+)
시급성 매우높음 + 지불의사 매우높음 + 기존지출 Y + 블루오션
A급 (7~9점)
시급성 높음 이상 + 지불의사 높음 이상
B급 (4~6점)
평균적인 시장성
C급 (~3점)
시장성 낮음, 우선순위 후순위
